# ChemLab — Химическая лаборатория «Атомы и вещества»

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
[![Content: CC BY 4.0](https://img.shields.io/badge/Content-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Интерактивная веб-лаборатория химии для школьного курса (8–11 класс): собирай молекулы из атомов вручную, смотри их в 3D, получай автоматическое описание вещества (формула, молярная масса, состав, свойства) и запускай реакции со стехиометрией. Центр приложения — граф веществ, который растёт по мере твоих открытий.

**Магазин атомов → рабочий стол 2D → 3D-инспектор → граф веществ.**

## Принципы

1. **Химия не врёт** — несуществующее вещество никогда не показывается как правильное; ошибка связи — обучающий момент.
2. **Сначала руки, потом теория** — сначала собери, потом читай объяснение.
3. **2D для манипуляции, 3D для понимания** — редактирование только на 2D-столе, 3D — для осмотра.
4. **Всё вычислимо — вычислено** — каждое число на экране производное от модели.
5. **Спека раньше кода** — ни одной фичи без требования в SPEC.md.

## Разработка

Проект разрабатывается по Spec-Driven Development: см. SPEC.md, раздел 2. Стек: React + TypeScript + Vite + Tailwind CSS, только клиент.

### Quickstart (этап M0 — ходячий скелет)

```bash
npm install     # зависимости
npm run dev     # dev-сервер → http://localhost:5173
npm test        # юнит- и приёмочные тесты (vitest)
npm run build   # продакшн-сборка в dist/
```

Что умеет M0 (US-1): берёшь в «Магазине атомов» O и два H (перетаскиванием или кликом), выбираешь кратность связи, тянешь «ручку связи» от O к каждому H → на столе собирается молекула, панель свойств показывает «Вода · H₂O · 18,015 г/моль · H 11,2 %, O 88,8 %», справа внизу — вращаемая 3D-модель воды (угол ~104,5°). Третий H к кислороду отклоняется с объяснением.

Структура кода — по SPEC.md, раздел 9: `src/domain` (вся химия, без DOM), `src/workspace` (2D-стол), `src/inspector3d` (3D), `src/graph` (панель свойств).
