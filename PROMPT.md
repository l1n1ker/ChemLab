# Стартовый промпт для Kimi Code CLI — сессия 1 (этап M0)

> Как использовать: положи всю папку `chemlab` в корень будущего репозитория, запусти `kimi` внутри неё, скопируй текст ниже первым сообщением.

---

Прочитай полностью AGENTS.md и SPEC.md — это источник истины проекта. Мы работаем по SDD: спека раньше кода, каждая фича ссылается на ID требования, критерии приёмки транслируются в тесты.

Задача этой сессии — **этап M0 «Ходячий скелет»** (SPEC.md, раздел 10).

## Скоуп

1. **Скаффолд**: React + TypeScript + Vite + Tailwind CSS; структура модулей по разделу 9 спеки (`src/domain`, `src/workspace`, `src/inspector3d`, `src/graph`). Скачай официальный текст AGPL-3.0 в LICENSE, создай NOTICE, добавь SPDX-заголовки по AGENTS.md. README.md уже есть — дополни его quickstart'ом по итогам.
2. **Domain Core (M0)**: справочник Element для H, O, C (контракт 6.1); AtomInstance, Bond; Molecule как связный компонент графа; валидация DR-1…5; формула по Хиллу, молярная масса, массовые доли; мини-каталог Substance для H₂O, H₂, O₂, CO₂, CO, CH₄, H₂O₂ с сопоставлением **по структуре** (DR-6), а не по формуле.
3. **Workspace 2D**: магазин атомов (FR-1, FR-3), перетаскивание, ручное создание связи с выбором кратности (FR-4), отказ с понятным объяснением при нарушении валентности (FR-5), разрыв связи (FR-7). Связная группа атомов автоматически становится перетаскиваемой молекулой.
4. **Панель свойств** (FR-6 в объёме M0): формула, молярная масса, элементный состав с массовыми долями; название для каталожных веществ; ярлык «гипотетическое соединение» для валентно-корректных некаталожных. Физические свойства — не в этом этапе.
5. **3D-инспектор**: шаростержневая модель выбранной молекулы, вращение и зум (FR-9, FR-10); геометрия каталожных по справочным углам (FR-11: вода ~104,5°, CO₂ линейная, метан ~109,5°), для прочих — эвристика с подписью «схематичная геометрия» (риск R2).
6. **Тесты**: юнит-тесты Domain Core покрывают DR-1…5 и вычисления; каждый критерий приёмки FR-1…11 (в M0-объёме) — тест-кейс. Тест без требования и требование без теста — дефект (SPEC.md, раздел 2).

## Ограничения

- Только клиент, без бэкенда (NFR-3). Вся химия — только в Domain Core; UI общается с ним командами и событиями.
- UI на русском, строки через i18n-словарь (NFR-5).
- Зависимости — только по LR-1 (MIT/BSD/Apache-2.0/GPLv3/AGPLv3); каждая новая — в NOTICE.
- Никаких выдуманных данных о веществах (принцип P1): нет в справочнике — честный ярлык.

## Критерий выхода M0

US-1 проходит end-to-end: беру из магазина атом O и два атома H, вручную соединяю O–H и O–H → три атома становятся молекулой, панель показывает «Вода · H₂O · 18,015 г/моль · H 11,2 %, O 88,8 %», в 3D-инспекторе — угловая модель воды, которую можно вращать. Попытка присоединить третий H к кислороду отклоняется с объяснением.
