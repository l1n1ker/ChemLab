# AGENTS.md — Химическая лаборатория «Атомы и вещества»

> Этот файл читается агентом автоматически. Главный источник истины проекта — **SPEC.md** (SDD-спецификация, ревизия v0.4). При конфликте этого файла и SPEC.md побеждает SPEC.md.

## Что за проект

Веб-лаборатория химии (школьный уровень, 8–11 класс): пользователь собирает молекулы из атомов вручную на 2D-столе, видит их в 3D, система автоматически распознаёт и описывает вещество (формула, молярная масса, состав, свойства) и запускает реакции со стехиометрией. Центр продукта — граф веществ. Open-source, код под **AGPL-3.0**, контент под CC-BY 4.0.

## Правила SDD (обязательны)

1. **Ни одной фичи без требования в SPEC.md.** Каждая фича ссылается на ID (`FR-x`, `DR-x`, `NFR-x`). Коммиты и код помечаются ID требований.
2. **Критерии приёмки → тесты.** Каждый Given/When/Then из SPEC.md — это тест-кейс. Требование без теста или тест без требования — дефект процесса.
3. **Изменение поведения = ревизия спеки.** Сначала правка SPEC.md с записью в Changelog, потом код. «Тихие» расхождения кода и спеки запрещены.

## Архитектура (SPEC.md, раздел 9)

Четыре модуля, обмен только командами и событиями:

- `src/domain/` — **Domain Core**: Element/AtomInstance/Bond/Molecule/Substance/Reaction, валидация DR-1…6, все вычисления (формула по Хиллу, молярная масса, массовые доли, моли↔граммы↔молекулы), движок реакций. **Чистая логика без UI и без DOM. Вся химия — только здесь.**
- `src/workspace/` — 2D-стол: рендер узлов, жесты, создание/разрыв связей. Никакой химии внутри.
- `src/inspector3d/` — 3D-инспектор (шаростержневая модель). Read-only потребитель модели; редактирование только в 2D.
- `src/graph/` — граф веществ и панель свойств; подписчик событий Domain Core.

## Ключевые доменные правила (SPEC.md, раздел 6.3, 14.3)

- DR-1…5: валидация связей по валентности; кратность; ионные — отдельным типом; различать «валентно-корректно, но неизвестно каталогу» (ярлык «гипотетическое соединение») и «некорректно» (отказ с объяснением).
- **DR-6: идентификатор вещества — структура (граф атомов и связей), не формула** (изомеры!).
- Принцип P1: **никогда не выдумывать свойства веществ.** Нет данных — честный ярлык, а не галлюцинация.

- UI на русском; все строки через i18n-словарь с первого дня (NFR-5).
- Зависимости — только по правилу LR-1 (SPEC.md, п. 13.4): MIT/BSD/Apache-2.0/GPLv3/AGPLv3. Новая зависимость = проверка лицензии + запись в NOTICE.
- Производительность: пересчёт панели свойств < 50 мс; 3D ≥ 30 FPS до 100 атомов (NFR-2).
